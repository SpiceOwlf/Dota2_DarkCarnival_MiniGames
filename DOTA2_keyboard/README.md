# Dota 2「机关人攻击」打字机器人

## 安装（只需一次）
1. Python 3.9 或更新版本，然后：
   ```
   pip install mss opencv-python numpy
   ```
2. Tesseract-OCR（已经装在 `C:\Program Files\Tesseract-OCR`）。只有字母模板认不出时才会用它，没有也能跑。
3. Dota 2 设置 → 视频 → 显示模式用 **窗口**（1600×1200）或 **无边框窗口**，不要用全屏独占。
4. **输入法切到英文**（或者微软拼音按 Shift 切到英文模式）。中文输入法会把按键吃掉。

## 使用
1. **校准**（只需一次；换分辨率或挪窗口后要重做）
   ```
   python calibrate.py
   ```
   5 秒倒计时内切到小游戏画面，然后拖框把**整个小游戏画面**框进去（从左上角的分数到右下角的边框，和录像的范围一样），按回车。
2. **预览识别效果**（推荐第一次做）
   ```
   python bot.py --preview
   ```
   你自己玩，窗口里会画出识别结果：绿框 = 已认出的词（下面写着认出的字母），橙框 = 还没认出。按 Esc 关闭。
3. **正式运行**
   ```
   python bot.py
   ```
   开始游戏后切到 Dota 2 窗口，按 **F8** 开始，再按 F8 暂停，按 **F12** 退出。
   只有 Dota 2 窗口在前台时才会按键，切到别的窗口不会乱打字。

## 它是怎么做的
- **找词**：没打的字母是白色，下一个要打的字母是黄色，打过的字母变灰。脚本只找白色和黄色的字母（灰的、被压暗的词自动忽略），所以找到的正好是“还要打的部分”。新词的第一个字母一定是黄的，用这个排除杂物。
- **认字母**：先用字母模板（`letters.npz`，从录像里学的，每个字母和样本比相似度，< 1 毫秒）；认不准再用 Tesseract。最后用拼音规则检查/纠错（比如 `BIJTA` → `BIJIA`）。
- **自动学习**：一串打完词就消失了，说明这个词认对了，它的字母会加进模板库，越用越准。退出时保存。
- **打字**：打错不扣分，所以直接把整个词一口气打出去；还可以把几个词连成一串打（`BATCH_WORDS`）。打完等 0.1 秒看结果：
  - 词消失了 → 打掉了；
  - 词还在 → 重新识别剩下的字母再打；
  - 连续 2 次没进展 → 把 26 个字母挨个按一遍（总有一个是对的）；
  - 连续 4 次 → 先跳过 1.5 秒，去打别的词。
- **先打谁**：出现得越早的越先打。好几个词首字母一样时，先只按一个字母，看游戏锁定了哪个词再接着打。

## 第一次实测请注意
这几件事只有进游戏才知道，请留意命令行输出 / `bot_log.txt`：
1. **按键游戏收不收得到**：按 F8 后应该看到 `✓ #12 XUANWO  0.25s  打了 1 次` 这样的行。如果一直是「没打掉」，看下面的常见问题。
2. **打字速度**：`打了 1 次` 越多越好。如果很多词要打 2~3 次，可能是按太快游戏漏键了，把 `bot.py` 顶部的 `KEY_GAP` 调大（比如 0.025）。如果都是 1 次，可以试着调小 `KEY_GAP`、`SETTLE` 来提速。
3. **锁定规则**：如果你发现游戏里一个词打到一半、按别的字母会跳到另一个词，告诉我，连串打字的逻辑要改。

## 常见问题
| 现象 | 处理 |
|---|---|
| 截图全黑 | Dota 2 改成“窗口”或“无边框窗口” |
| 一直「没打掉」，游戏里字母不变灰 | 确认 Dota 窗口在前台、输入法是英文；仍不行就用“以管理员身份运行”打开命令行 |
| 预览里框不住字 / 字没被认出来 | 重新校准，确认框的是整个小游戏画面；把 `debug` 文件夹里的截图发给我 |
| 很多词要打好几次 | 调大 `KEY_GAP`；或者把 `bot_log.txt` 发给我 |
| 命令行提示「Dota 2 不在前台」 | 点一下 Dota 窗口 |

## 文件
- `bot.py` 主程序；`calibrate.py` 校准；`pinyin.py` 拼音校验/纠错；`letters.py` 字母模板识别
- `letters.npz` 字母模板库（自动更新）；`config.json` 校准结果
- `bot_log.txt` 运行记录；`debug/` 卡住时的截图（最多 40 张）
- 离线测试：`python bot.py --replay record/game_explain_video.mp4`（加 `--show` 看画面）
