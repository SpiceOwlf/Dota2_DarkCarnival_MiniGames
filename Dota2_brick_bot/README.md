# Dota 2 打砖块机器人 v7.1

## 安装（只需一次）
1. 安装 Python 3.9 或更新版本，安装时勾选 “Add Python to PATH”。
2. 把 `bot.py`、`calibrate.py` 放进同一个文件夹，在这个文件夹里打开命令行，运行：
   ```
   pip install mss opencv-python numpy
   ```
3. Dota 2 设置 → 视频 → 显示模式用 **窗口** 或 **无边框窗口**（不要用全屏独占）。

## 使用
1. **校准**（只需一次；换分辨率或移动窗口后要重做）
   ```
   python calibrate.py
   ```
   倒计时 5 秒内切到打砖块画面（窗口模式、无边框都可以，画面不要被挡住）。截图后弹出一个窗口，拖个框把**整个打砖块画面**框进去就行，不用很精确，脚本会自动收紧到两根柱子之间。按回车确认后，打开 `calib_check.png`，看看绿框是不是正好框住了游戏区。
   - 如果 Dota 窗口挪了位置或者改了大小，要重新校准一次。
2. **预览识别效果**（可选，推荐第一次做）
   ```
   python bot.py --preview
   ```
   你自己玩，窗口里会画出识别结果：绿圈是马车，黄圈是靴子，小绿框是能打碎的砖，青色框是死砖块，红色折线是脚本打算让靴子走的路线。按 Esc 关闭。
3. **正式运行**
   ```
   python bot.py
   ```
   切到 Dota 2 窗口后按 **F8** 开始，再按 F8 暂停，按 **F12** 退出。

## 它会做什么
- **砖块分级**：绿色砖（打掉加一条命）价值最高（`GREEN_VALUE`，约 2~3 块金砖），金色砖（+50）其次，橙色、米色再次，淡蓝色死砖块 0 分。预览窗口里：绿框 = 加命砖，黄框 = 金砖，橙框 = 橙砖，白框 = 米色砖，青框 = 死砖块。
- **考虑靴子的宽度**：比靴子窄的缝（比如死砖块之间的小缝）不会再被当成能钻过去，所以不会再反复往死砖块上打；会改走两侧的空道绕到砖块上方去打。
- **瞄准拿分**：靴子下落时，把每个可选角度都完整模拟一遍——撞砖、撞墙都会反弹（分得清撞的是砖的侧面还是底面），打碎的砖从模拟里去掉，一直算到靴子落回来。选「一路上拿分最多」的角度，金砖额外加分。这样会自然地把靴子送进砖块后面的空隙里来回弹。
- **先拿分再过关**：砖还多的时候，飞出顶部的路线会被扣分（不主动过关）。满足下面任一条件才开始找出口：剩下的砖价值低于开局的 25%（`EXIT_FRACTION`）、这关打了 150 秒（`LEVEL_TIME_CAP`）、这关已经掉了 2 条命（`EXIT_AFTER_MISSES`）。命令行会打印「开始找出口过关」。
- **钻小口 / 绕过死砖块**：每 1° 模拟一次角度（以前是 3°），能找到死砖块墙上的小口子，也能找到「先撞侧墙再斜着钻进去」的路线。选角度时按「期望得分」算：考虑到瞄准有误差，口子越窄、命中概率越低，期望分就越低——口子后面金砖够多才值得去试，不然先打别处稳定的分。
- **多看一步**：每个候选角度都模拟两下——这一下拿多少分、靴子落在哪；再从那个落点算下一下最多能拿多少分。所以会主动「先把靴子送到合适的位置，再打进圆圈/洞口里面」。状态里的 `+next…` 就是预计下一下的分。想关掉：`LOOKAHEAD = False`。
- **自动学习瞄准误差**：每次反弹都对比「想打的角度」和「实际弹出去的角度」，命令行会打印「想打 +12°，误差 +3°（平均误差 4.2°）」。误差越小，越敢钻窄口子。
- **马车停得更准**：自动学习松开方向键后马车还会滑多远，提前松键。状态行会显示「瞄准误差≈…°  滑行≈…w」。
- 靴子上升时，用同一个模拟预测它撞砖弹回来的落点，马车提前过去等；要撞 3 次以上才落下（不确定）时，往中间靠。
- 靴子从顶部飞出去后，等过关黑屏，不会再误按发射。
- 想关掉瞄准、只管接住：把 `bot.py` 顶部的 `AIM = True` 改成 `AIM = False`。
- 识别过关黑屏（画面变黑、马车消失，并且持续 0.4 秒以上才算过关）。新关卡淡入后开始发射：每 0.45 秒按一次空格，**一看到靴子飞出去就停**，最多按 5 次（先锁定马车，再扔出靴子；中间有一下没被游戏收到也没关系）。
- 掉了一只靴子（丢一条命）后，先等 **3.5 秒**，让靴子回到马车上，再开始发射。想改等待时间，就改 `bot.py` 顶部的 `LOST_LIFE_DELAY`。
- 同时跟踪画面里所有会动的棕色东西，只让「像靴子一样匀速飞」的那个来指挥马车。几乎不动的东西（墙边的爪子、砖块碎屑）会被认出来并屏蔽 30 秒。
- 连续 6 次发射都没看到靴子（比如游戏结束、弹出菜单），会自动暂停。
- 运行记录保存在 `bot_log.txt`。
- 每次**漏接**、发射、过关、或者出现被忽略的短暂黑屏时，会把之前约 1.5 秒的画面拼成一张图，存到 `debug` 文件夹（最多保留 40 张）。图上黄圈 = 脚本认为的靴子位置，红线 = 马车要去的位置，绿线 = 马车现在的位置。漏接的截图文件名带 `miss`，命令行也会打印「漏接？靴子最后在 x=…，马车 x=…，目标 x=…」。出问题时把对应的图发给我就行。不想保存可以用 `python bot.py --no-debug`。

## 常见问题
| 现象 | 处理 |
|---|---|
| 截图全黑 | Dota 2 改成“无边框窗口” |
| 脚本在动但游戏不响应按键 | 确认 Dota 窗口在前台；仍不行就用“以管理员身份运行”打开命令行 |
| 马车来回抖 | 把 `bot.py` 顶部的 `DEADZONE` 调大（例如 0.03） |
| 想更早/更晚过关 | 调 `EXIT_FRACTION`（越小越晚走、分越高但风险越大）和 `LEVEL_TIME_CAP` |
| 瞄准后反而容易漏接 | 把 `AIM_MAX` 从 28 改小（例如 16），或者先关掉瞄准，再把 `bot_log.txt` 发给我 |
| 马车总是慢半拍 | 把发给我的 `bot_log.txt` 和一段录屏发给我，我来调参数 |
